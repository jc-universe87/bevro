# BEVRO — Brief Logo & Brand Manual

## 1. Brand idea
**Bevro** is a productivity and agent-work platform built around one promise:

**Get things done.**

The brand should feel:
- capable
- modern
- practical
- intelligent
- dependable
- active, but not aggressive
- human-first, not “AI-hype”

---

## 2. Logo
### Primary logo
Use the **Bevro logomark + wordmark + two-line tagline**.

Tagline layout:

**AGENTS THAT**  
**GET THINGS DONE**

### Logomark
The mark is a layered forward-motion symbol:
- suggests movement and execution
- represents multiple agents/workers moving toward one outcome
- should feel software-first rather than industrial

### Clear space
Keep clear space around the logo equal to roughly the height of the lowercase **e** in “Bevro”.

Do not:
- stretch or distort
- rotate
- add effects
- alter the proportions
- recolour individual parts arbitrarily

---

## 3. Colour direction
Current palette is provisional but should stay within this family:

- **Burgundy** — mature, decisive, capable
- **Mauve** — modern, digital, collaborative
- **Warm gold/champagne** — constructive, valuable, energetic
- **Near-black / charcoal** — primary wordmark and text
- **Off-white** — preferred background

Suggested working values:

- Burgundy: `#7A1837`
- Deep Burgundy: `#5E1029`
- Mauve: `#A86D82`
- Soft Mauve: `#C596A7`
- Warm Gold: `#E7C080`
- Charcoal: `#17181C`
- Off White: `#F8F7F4`

Use colour sparingly. The interface should remain neutral and clean.

---

## 4. Typography
For now use a system-safe sans serif:

`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`

### Wordmark
- bold
- clean
- geometric
- confident
- no decorative styling

### Tagline
- uppercase
- smaller than wordmark
- moderate letter spacing
- use burgundy/mauve rather than grey

---

## 5. Brand tone
Bevro should communicate:

**“This gets work done for me.”**

Avoid language that feels:
- overly technical
- robotic
- futuristic for its own sake
- wellness-oriented
- vague or inspirational without purpose

Prefer:
- clear
- concise
- practical
- confident
- action-oriented

---

## 6. UI relationship
The product UI should reflect the same principles:

- minimal home screen
- one clear action at a time
- quiet neutral surfaces
- burgundy/mauve/gold only as accents
- no card overload
- progressive disclosure
- strong whitespace
- simple, direct language

---

## 7. Current status
The current logo is **provisional** and may still be refined.

Likely future refinements:
- exact vector paths
- gradient balance
- final wordmark spacing
- final colour values
- dark-mode logo variant
- icon/app/favicon variants
- monochrome version

For now, use the current logo consistently across the app and GitHub materials.
